# Smart India Hackathon (SIH)

Repository for Smart India Hackathon Project.

## Branch Workflow
- **`main`**: Production / release branch (stable, tested releases only)
- **`staging`**: Pre-production integration & verification branch
- **`internal/prototype`**: Integrated prototype hub (where internal components are merged)
- **`internal/prototype-UI`**: Frontend & 3D simulation prototype
- **`internal/prototype-ML`**: AI/ML models & analytics prototype
- **`internal/prototype-HD`**: Hardware & sensor firmware prototype
